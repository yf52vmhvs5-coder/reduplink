TRANSMISSION

HOW A RUN WORKS

Each session draws from a curated deck, shuffled into a fixed-length run. The HUD tracks question index, score, and remaining lives. After you lock an answer, a short fact may appear — trivia as a signal, not filler.

DECK

Solo play skips questions already shown since this page was opened, and only repeats them when the fresh pool runs short. A reload clears that memory. Online, both sides build from the host's seed, so that local memory stays out.

SCORE

Every correct answer adds ten points. In Blitz, each second still on the clock adds half a point, rounded down. The end screen keeps a best for that mode in this browser; an online best is your own score, stored apart from solo.

SIGNAL TINT

In the game menu, the RU frame cycles accent color. That tint is saved here too — the same phosphor thread as Nebula Void and the studio deck.

MODES

CLASSIC · SURVIVAL · BLITZ

  • CLASSIC

    Move on

    A wrong answer costs one life. If any lives remain, the next question comes up either way. Zero lives ends the run short of fifty.

  • SURVIVAL

    Hold the line

    Miss and you lose a life, but the same question stays until you answer it — or until you are out of lives. In a room it stays until every player who still has lives has answered it.

  • BLITZ

    Fifteen seconds

    Each question gets a fifteen-second clock. Time out counts as a miss and costs a life, unless a shield is up. A correct answer scores 10 plus half a point per second left, rounded down — a full clock is +7.

STARDUST

RELAY

2-PLAYER ROOM

Create a room or join with a six-character code — two players maximum. The host picks the mode; both run the same question order. Peer relay handles sync; you stay in the browser.

HOST

Creates the room, shares the code, and chooses Classic, Survival, or Blitz before the run starts.

GUEST

Joins with the code and waits for the host to start. Same deck, separate scores, lives, and Stardust. Classic and Survival wait until both living players have answered. Blitz can close the question on the clock.

SPECTRUM

8 TOPICS

Questions pull from space science, worlds, physics, technology, and the odd corner cases in between. Wrong answers are built to look plausible, not random.
